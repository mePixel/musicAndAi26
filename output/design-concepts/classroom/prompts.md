# Classroom website concepts

Five revised website UI concepts generated with the built-in image generation tool.

## 1. Sunday Rehearsal

[View image](01-sunday-rehearsal-web.png)

Prompt:

Use case: ui-mockup. Design a polished FRONTEND WEBSITE screenshot for bodybeat, a webcam rhythm game, with drummer-classroom personality. One landscape 1536x1024 desktop web layout. Crucial: IT IS A WEBSITE, not a photograph of a room, a physical chalkboard, a notebook, or a set of objects with buttons printed on them. All interface elements must be flat, front-facing, crisply aligned to an intentional web grid, with clear navigation, comfortable spacing, realistic type sizes, and large clickable controls. No perspective distortion, no tabletop mockup, no giant photoreal backdrop. Use classroom aesthetics through palette, typography, small illustrations, subtle materials and musical notation. Art may take up at most 30 percent of screen; useful UI and whitespace should dominate. A distinctive playful web product, not generic SaaS.
Shared exact content: small "bodybeat" wordmark top left, header links "Practice" and "How to play" right. Short intro "Pick a track. Move to the beat." Two selectable track controls "First Groove" / "96 BPM · 0:40" and "Disco Circuit" / "120 BPM · 0:36", selected First Groove with visible check. A clean waveform for selected song. Camera / Keyboard segmented toggle and large "Let's play" button. Footer "Your body is the instrument." Keep everything readable with strong contrast. No extraneous slogans, fictitious social proof, courses, stats, accounts, orange or Matrix aesthetic. Render as an actual beautifully designed web interface, no browser chrome. Warm white page background, navy ink, butter yellow and burgundy highlights. A welcoming editorial website with headline 'Find your rhythm.' in large friendly serif, small restrained line drawing of drum kit beside it. Thin horizontal rules. Two generous side-by-side song panels below, editorial typography with large 01/02 and subtle pale blue selection, flat surfaces. Selected song waveform extends across page beneath panels. Bottom horizontal control bar contains input toggle and burgundy Play button. Small musical teaching marks create charm. Warm music-school atmosphere through design, no room illustration.
